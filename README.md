# EarthCardGame 🌍🃏

אפליקציית משחק קלפים רספונסיבית ואינטראקטיבית המבוססת על מיקום גיאוגרפי ומנוע שמע מתקדם, שנבנתה ב-SwiftUI.

## ✨ תכונות מרכזיות (Features)

* **לוגיקת מיקום (CoreLocation):** חלוקה דינמית של השחקן ל-East Side או West Side על פי קו האורך של ה-GPS בזמן אמת.
* **ניהול מחזור חיים (LifeCycle):** עצירה אוטומטית מוחלטת של השעון הפנימי ומוזיקת הרקע במעבר לרקע (`inactive`/`background`), וחזרה מדויקת לאותה נקודה עם פתיחת האפליקציה.
* **מערכת שמע ייעודית (AVFoundation):** מוזיקת רקע מתמשכת בלופ, אפקט היפוך קלפים מיידי (`flip`), והשתקה אוטומטית של הרקע לטובת צליל ניצחון (`win`) עוצמתי במסך הסיכום.
* **שמירת נתונים וניווט:** שימוש ב-`@AppStorage` לזיכרון שם המשתמש, וניהול נכון של מחסנית המסכים (`NavigationStack`) כולל חסימת חזרה אחורה למשחק שהסתיים.
* **עיצוב מותאם (Dark Mode):** תמיכה מלאה ברמת המערכת במצב יום/לילה ובמצב אנכי (Portrait).
